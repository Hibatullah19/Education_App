# Education App 📚

A Flutter-based education application built with **Flutter and Dart**.

## 📱 Project Overview

**Education App** is a Flutter application designed with a clean and simple user interface.
The project currently includes two main screens:

* `home_page`
* `next_page`

The project focuses on building the UI and navigation structure using Flutter.

## ✨ Features

* Clean and simple Flutter UI
* Home page
* Next page
* Screen navigation
* Responsive layout

## 🛠️ Technologies

## 🚀 Getting Started

### Prerequisites

Make sure you have Flutter installed on your machine.

### Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Navigate to the project directory:

```bash
cd education_app
```

Get the dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```
